本版将插件更名为 **Qinghui 看图助手 / dsh-qinghui-vision**，解决与社区已有 `dsh-vision-kit` 项目的名称冲突。原仓库历史和 0.1.0 Release 保留。

- 包名：`dsh-qinghui-vision`。
- 工具：`qinghui_vision_read_image`、`qinghui_vision_compare_images`。
- 独立命令行：`dsh-qinghui-vision`。
- 保留截图解读、OCR、多图对比、云端兼容视觉接口及本地 Ollama 支持。

桌面版先完全退出，再安装：

```sh
dsh plugin --profile desktop add "https://github.com/qinghuidaqzp/dsh-qinghui-vision/releases/download/v0.1.1/dsh-qinghui-vision-0.1.1.tgz"
```

旧版用户请先记录配置并移除 `dsh-vision-kit`，再安装新版、恢复模型与凭据设置；Web 版将 `desktop` 替换为 `web`。不要同时启用新旧版本。

针对 DeepSeek Harness 0.2.2-rc.2 验证。真实识图仍需自行配置视觉模型；本次验证不包含真实模型推理质量评测。源码与详细配置见 [README](https://github.com/qinghuidaqzp/dsh-qinghui-vision#readme)。
