首版为 DeepSeek Harness 增加截图解读、OCR 和多图对比。通过两个原生工具调用配置的视觉服务，支持云端兼容 API 和本机 Ollama。

安装到桌面版前，请先完全退出 DeepSeek Harness：

```sh
dsh plugin --profile desktop add "https://github.com/qinghuidaqzp/dsh-vision-kit/releases/download/v0.1.0/dsh-vision-kit-0.1.0.tgz"
```

Web 版将 `desktop` 改为 `web`。重启后在 `vision-kit` 插件设置中填写视觉模型与凭据；本地 Ollama 可使用 `http://localhost:11434/v1` 并开启 `allowLocalServer`。

- 已验证 Harness 0.2.2-rc.2；34 项自动化测试通过。
- 支持 PNG、JPEG、WebP，默认最多 4 张、单张 10 MiB。
- 包含内存缓存、超时、取消和明确的截断提示。
- 真实模型推理尚未验证，识图质量由配置的模型决定。

下载附件 `.tgz` 即为预构建安装包，不需要额外构建授权。`SHA256SUMS.txt` 可用于校验下载内容。完整配置见 [README](https://github.com/qinghuidaqzp/dsh-vision-kit#readme)。
